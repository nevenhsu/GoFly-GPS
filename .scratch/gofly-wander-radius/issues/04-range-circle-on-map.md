# 04: 地圖藍色虛線範圍圈

**What to build:** E1、E2、E2.b 的地圖以真實公尺半徑畫藍色虛線圈（2 pt 虛線、8% 淡藍填色），隨地圖縮放等比變化。圓心為範圍錨點（E1、E2 相同）：只在停止自動漫步後以地圖 Pin 瞬移到新位置時移到新位置，手動搖桿移動不帶著圓走，E2.b 拖滑桿時即時預覽。

**範圍圈開關：** 搖桿與自動漫步（E1、E2）的 MapControls 在「回到定位」上方新增「範圍」按鈕（`icon/radius`，44 × 44 pt，間距 8 pt），點擊顯示／隱藏範圍示意圓圈。預設開啟（開啟時圖示為系統藍）。開關只影響圓圈顯示，不影響半徑與選點限制。Figma 已畫開啟狀態 Light／Dark；關閉狀態（圖示灰）與是否跨重開保留尚未設計／確認。

**Blocked by:** 01 (漫步半徑模型與偏好持久化), 03 (km chip 與設定漫步範圍 sheet)

**Status:** ready-for-agent

- [ ] 圈半徑與設定值一致（以地圖距離驗證 0.1 / 5 / 100 km）
- [ ] 縮放地圖時圈跟著比例變化，不遮住 Pin、箭頭與路線的互動
- [ ] 範圍按鈕位置、尺寸、間距依 Figma（E1、E2 Light／Dark），觸控區至少 44 pt，有 VoiceOver 標籤（顯示／隱藏範圍）
- [ ] 首次預設顯示圓圈；點按鈕隱藏／顯示，隱藏時半徑、選點限制不變
- [ ] 搖桿移動時圓不跟隨；停止漫步後 Pin 瞬移成功圓才移到新位置；漫步中圓固定
- [ ] E2.b 拖滑桿時圈即時更新；完成後 E1／E2 圈與 chip 一致
- [ ] Light／Dark 配色依 Figma，Simulator 截圖各一組
