# Release 說明撰寫規格

依 2026-11-02 使用者確認的 v1.0.6 Release 格式，後續 GitHub Release 沿用以下規則。

## 語言與排列

- **英文在前，繁體中文在後**，兩段內容相互對應。
- 不加「English」、「繁體中文」等語言標題或標籤。
- 英文與中文段落之間以水平分隔線 `---` 區隔。
- 版本與 build 摘要只在說明開頭出現一次，例如 `GoFly GPS 1.0.6 — iOS build 40 / Mac build 4.`；中文段落前不重複。
- Release 標題使用正式品牌與版本，例如 `GoFly GPS 1.0.6`。

## 內容結構

英文依序使用 `Changes`、`Downloads and installation`、`Verification and limitations`；中文對應 `更新內容`、`下載與安裝`、`驗證與限制`。各節使用二級標題。

- 更新內容：簡明描述該版本帶給使用者的變更。
- 下載與安裝：列出實際發行的 DMG、IPA 與對應 checksum，檔名必須與上傳資產一致；保留適用的安裝說明。
- 驗證與限制：區分已完成的軟體／套件檢查與尚未完成的實機／乾淨 Mac 驗收；只陳述有證據支持的結果，不把未確認事項寫成已修復。
- 使用者要求刪除的句子應同步從中英文移除，不在後續編輯時自行補回。本次 v1.0.6 已移除「地圖鏡頭調整前後線條視覺粗細變化的原因尚未確認，2 pt 設定不代表該現象已修復。」及其英文對應內容；這是發行說明的刪文要求，不代表問題已修復，也不要求刪除內部調查紀錄。

- v1.0.6 不包含「設定值空間不足時移至標題下方顯示」這項修改；中英文發行說明均移除此錯誤描述，後續不得補回。定位權限警告與已允許狀態的更新說明保留。

## 更新與核對

修改既有 Release 前先讀取目前說明，保留未要求變更的內容。更新後讀回 GitHub 內容，確認語言順序、版本摘要僅出現一次、沒有語言標籤，以及中英文修改一致。

版本號與 build 遵循 [升版規則](VERSIONING.md)；撰寫或更新 Release 說明不授權自動升版。
